# تطبيق عملي (Amali APK Builder)

هذه الحزمة جاهزة تماماً لبناء ملف أندرويد APK تلقائياً ومجاناً عبر GitHub Actions من الهاتف أو اللابتوب دون الحاجة لتثبيت Android Studio.

## خطوات استخراج ملف الـ APK من GitHub:
1. فك الضغط عن ملف `amali-github-apk-builder.zip`.
2. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub باسم `amali-app`.
3. ارفع جميع الملفات والمجلدات الموجودة داخل الحزمة إلى المستودع.
4. افتح تبويب Actions في مستودعك، وستجد عملية البناء Build Android APK تعمل تلقائياً (أو اضغط Run workflow).
5. بعد اكتمال البناء (حوالي 3 دقائق)، انزل إلى قسم Artifacts في صفحة العملية وحمّل ملف `Amali-Android-APK` الذي يحتوي على `app-debug.apk` الجاهز للتثبيت على هاتفك الأندرويد.
